# Mirantis Container Products and PHP2Shell (CVE-2026-109618, CVE-2026-109619): Not Vulnerable

### Release Date
2026-10-27

### Overview

On October 21, 2026, the PHP project released PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35 to fix two critical vulnerabilities in the PHP interpreter, collectively referred to as **"PHP2Shell"**. Details of the vulnerabilities leaked publicly on October 20, ahead of the coordinated disclosure date. Both flaws are in the error-handling paths of PHP core and allow an unauthenticated remote attacker to achieve **Remote Code Execution (RCE)** against any web application served by a vulnerable PHP interpreter:

- **[CVE-2026-109618][]**: memory corruption when PHP runs out of memory while setting up a request.
- **[CVE-2026-109619][]**: use-after-free of global state left behind by a fatal error, which a later request handled by the same worker process can act on.

Exploitation in the wild has been reported.

### Unaffected Products

**Mirantis Container Runtime (MCR), Mirantis Kubernetes Engine (MKE) 3 and 4, and Mirantis Secure Registry (MSR) 2, 3 and 4 are not vulnerable to CVE-2026-109618 or CVE-2026-109619.** None of these products contain, install or execute PHP.

**Customers using these products do not need to take any action for the products themselves.**

Container images that customers run on MCR or MKE, or store in MSR, may include a vulnerable PHP interpreter. Customers should identify containerized PHP applications and rebuild their images on a fixed PHP release.
